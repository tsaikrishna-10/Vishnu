# VISHNU Android build

This branch introduces a native Android application module alongside the existing Vercel-hosted web app.

## Product direction
- Android-first native app using Kotlin and Jetpack Compose
- Custom futuristic dark interface with emerald accents
- Preserve the existing VISHNU TMDB proxy and Firebase project
- Add catalogue, accounts, library, playback and downloads in staged modules

## Current foundation
- Gradle multi-project setup with an `:app` Android application
- Compose home screen and bottom navigation
- Android internet permission
- Retrofit/Gson and Coil dependencies ready for the catalogue integration

## Build requirements
- Android Studio with JDK 17
- Android SDK Platform 35
- Gradle wrapper generated by Android Studio (not committed yet)

Open the repository in Android Studio and sync Gradle. The current screen is a UI foundation; TMDB data, Firebase sign-in, player integration and download management are the next implementation stages.
